                           TROUBLESHOOTING
════════════════════════════════════════════════════════════════

❓ COMMON ISSUES:

🔧 Servers won't start:
• Run INSTALL.bat as Administrator first
• Check Windows Firewall settings
• Verify no other software uses ports 15400/15500

🔧 Can't connect with client:
• Ensure servers are running (STATUS.bat)
• Check client server settings: localhost:15400
• Verify firewall allows connections

🔧 Poor performance:
• Enable Performance Mode in MANAGE.bat
• Close unnecessary programs
• Ensure adequate RAM (4GB+ recommended)

🔧 Security warnings:
• This is normal - modern anti-cheat is very sensitive
• Check logs for detailed information
• Adjust security level in configuration if needed
