🚀 SUPER QUICK START (3 STEPS):

  STEP 1: INSTALL
  ═══════════════
  • Right-click on INSTALL.bat
  • Select "Run as administrator"  
  • Wait for installation to complete

  STEP 2: START SERVERS  
  ══════════════════════
  • Double-click START-SERVERS.bat
  • Wait for all 3 servers to start
  • You'll see 3 server windows open

  STEP 3: CONNECT & PLAY
  ══════════════════════
  • Configure your client:
    - Server: localhost
    - Port: 15400
  • Connect and enjoy Flyff 2.0!

════════════════════════════════════════════════════════════════

✅ SUCCESS INDICATORS:

• All 3 server windows stay open
