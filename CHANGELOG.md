# Madrigal Ascension - Changelog

All notable changes to Madrigal Ascension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-XX - "Foundation Release"

### 🎉 **Major Changes - Complete Rebranding**

#### Added
- **Complete rebranding** from FlyForFruit to "Madrigal Ascension"
- **Modern project structure** with organized directories
- **CMake build system** replacing legacy Visual Studio projects
- **Cross-platform support** with Linux and macOS compatibility
- **Modern C++17 codebase** with enhanced performance
- **Comprehensive configuration system** with centralized settings
- **Professional branding** with consistent naming throughout
- **Legacy compatibility layer** for smooth transition
- **Modern build scripts** for Windows (Build.bat) and Unix (build.sh)

#### Technical Infrastructure
- **MadrigalClient.h/cpp** - Modern client architecture
- **MadrigalConfig.h** - Centralized configuration system
- **Version.h** - Comprehensive version management
- **ServerConfig.ini** - Modernized server configuration
- **CMakeLists.txt** - Professional build system
- **Resource/MadrigalAscension/** - New resource structure
- **branding.inc** - Centralized branding resources

#### Project Structure
```
Madrigal Ascension/
├── Source/
│   ├── MadrigalClient/     # Modern client code
│   └── Servers/            # Server modules
├── Config/                 # Configuration files
├── Resource/
│   └── MadrigalAscension/  # New branding resources
├── CMakeLists.txt         # Modern build system
├── Build.bat              # Windows build script
└── build.sh              # Unix build script
```

### 🔄 **Migration from Legacy**

#### Changed
- **Application name**: FlyForFruit → Madrigal Ascension

- **Version system**: Modern semantic versioning (1.0.0)
- **Build system**: Visual Studio projects → CMake
- **Configuration**: Scattered settings → Centralized config

#### Legacy Compatibility
- **Backward compatibility** maintained for existing saves
- **Legacy defines** mapped to new Madrigal equivalents
- **Protocol compatibility** with existing Flyff V19 base
- **Graceful migration** path for existing installations
